# TesseraOS Minimal — специфікація інтерфейсу

Фіксована айдентика проєкту. Користувач не збирає тему з нуля: він отримує
один витриманий стиль і два перемикачі — світла/темна та щільність.

Мінімалізм тут — не «менше кольору», а менше **шарів**: один акцент замість
secondary/tertiary-ролей у UI, hairline замість тіней, типографіка замість
рамок.

## 1. Палітра

Два набори нейтральних тонів (світлий і темний) плюс **один** акцент.

| Роль | Світла | Темна | Де застосовується |
|---|---|---|---|
| `mmSurface` | `#F7F7F8` | `#0E0F13` | підкладка всіх екранів |
| `mmRaised` | `#FFFFFF` | `#14161A` | поле пошуку, плитка QS, сповіщення |
| `mmInk` | `#14161A` | `#E8EAED` | основний текст |
| `mmMuted` | `#6C7079` | `#9AA0AA` | другорядний текст, значення праворуч |
| `mmHair` | `#E2E3E6` | `#262A31` | розділювачі, обводки, вимкнений перемикач |
| `mmAccent` | `#3350C8` | `#A9BBFF` | рівно один елемент на екран |
| `mmOnAccent` | `#FFFFFF` | `#0A1436` | текст на акценті |

Правила:

1. Акцент — **один** на екран. Два акценти поруч означають, що один з них
   помилковий.
2. Ролі MD3 `secondary` і `tertiary` у цьому стилі не мають видимого
   застосування. Вони лишаються визначеними в палітрі (щоб сторонні
   застосунки не зламалися), але системний UI їх не використовує.
3. Статуси: `mmError #BA1A1A` / `#FFB4AB` — лише для деструктивних дій.
4. Контраст: `mmInk` на `mmSurface` ≥ 12:1, `mmMuted` ≥ 4.5:1,
   `mmHair` не використовується як носій тексту.

## 2. Геометрія

| Токен | Значення | Нотатка |
|---|---|---|
| базова сітка | 8 dp | усі відступи кратні 8, крім бокового поля |
| бокове поле | 20 dp | текст і списки вирівняні по ньому |
| радіус керування | 10–12 dp | кнопки, поля, плитки |
| радіус контейнера | 26 dp | «екран» пристрою, нижні sheets |
| рядок списку | 52 dp | мінімум; не 64 |
| hairline | 1 dp | замість будь-якої тіні |
| тайл іконки | 46 dp | радіус 12 dp |
| штрих піктограми | 1.5 dp | моноліні, без заповнених варіантів |
| elevation | 0 | тіней у стилі немає взагалі |

## 3. Типографіка

Roboto Flex, ваги **300 / 400 / 500**. Напівжирний (600+) не використовується:
ієрархію робить розмір і вага 500, а не жирність.

| Стиль | Розмір | Вага | Tracking | Призначення |
|---|---|---|---|---|
| `display` | 52 sp | 300 | −2.0 | годинник на локі |
| `title` | 20 sp | 400 | −0.3 | заголовок екрана |
| `body` | 13.5 sp | 400 | 0 | рядки списків |
| `label` | 12.5 sp | 400 | 0 | значення праворуч, підписи |
| `section` | 10.5 sp | 500 | +1.0 | мітки секцій, ВЕРХНІМ РЕГІСТРОМ |
| `meta` | 10.5 sp | 400 | 0 | рядок стану, таймстемпи |

## 4. Рух

- стандартний перехід — 120 ms, emphasized — 200 ms, `ease-out`;
- єдині допустимі трансформації: fade і translate на 2 dp;
- без пружин, без overshoot, без паралаксу;
- у режимі «зменшити анімації» — 0 ms, стан змінюється миттєво.

## 5. Заборони

Стиль вважається зламаним, якщо з'являється будь-що з переліку:

- тіні та elevation для розділення поверхонь;
- blur / «скло» / градієнти на підкладках;
- картка-в-картці;
- два акцентні елементи на одному екрані;
- кольорові іконки сторонніх застосунків у лаунчері (тільки монограми);
- ресурси, анімації чи іконки з прошивок Pixel — це чужий бренд;
- більше трьох ваг шрифту на екрані.

## 6. Екрани й їх відмінність від стоку

| Екран | Що змінено |
|---|---|
| Блокування | один рядок стану замість кількох, годинник 300 ваги, сповіщення — одна картка, розблокування по hairline-штриху |
| Домашній екран | монохромні монограми замість кольорових іконок, пошук-поле зверху, док із hairline-розділювачем |
| Налаштування | плоский список із hairline замість карток, мітки секцій маленькі й розряджені, значення приглушені праворуч |
| Quick Settings | плитки стану 2 колонки, стан читається з фону, слайдер яскравості — 2 dp hairline |

## 7. Відображення в коді

Специфікація реалізується двома шарами, без форкання AOSP:

**RRO-оверлей** `overlay/themes/TesseraMinimalTheme/` (ціль `android`):

| Токен специфікації | Ресурс framework |
|---|---|
| `mmSurface` | `colorSurface` у `Theme.DeviceDefault*` |
| `mmInk` / `mmMuted` | `colorOnSurface` / `colorOnSurfaceVariant` |
| `mmHair` | `colorOutlineVariant` |
| `mmAccent` | `colorPrimary` + `colorSecondary` (однаково, щоб сторонні застосунки не «вистрибували» в інший колір) |
| elevation 0 | `*Elevation` dimens у стилів DeviceDefault |
| радіуси | `shapeAppearance*` |

**Застосунки** `apps/` (Compose + Material 3): токени звідси ж, через
власний `TesseraTheme.kt`, щоб лаунчер і Settings-шкіра не роз'їжджалися
з оверлеєм.

Порядок роботи: спершу `TesseraMinimalTheme` як RRO (він змінює всю
систему), потім own-app, де hairline й монограми потребують власного
компоунент-коду.

## 8. Що ще не вирішено

- чи лишаємо монограми в лаунчері, або робимо опцію «показувати оригінальні
  іконки» (без неї частина користувачів не знайде застосунок);
- щільність:Compact/Regular як другий перемикач ще не специфікована;
- логотип і айдентика проєкту не розроблені — зараз тільки інтерфейс.
