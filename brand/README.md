# Айдентика TesseraOS

Тут лежить те, що робить дистрибутив впізнаваним: знак, напис, шрифти,
кольори-основи та шпалери. Це не «дизайн-макет заради макета» — у кожного
файла є споживач у репо.

```
brand/
  logo/        знак, моно-варіант, lockup, фавіконка (SVG)
  android/     той самий знак як VectorDrawable — єдиний формат, що йде в образ
  fonts/       брендові шрифти (woff2-підмножини) + ліцензії OFL
  wallpapers/  шпалери 1080×2400 (JPG) — джерело для site/wallpapers і для образу
  LOGO.md      побудова знака, охоронне поле, заборони
  TYPE.md      шрифти, покриття кирилиці, як підключити в Android
  PALETTE.md   колір-основа й як з неї рахується палітра
```

## Чому власна айдентика, якщо інтерфейс «як Pixel»

Геометрія, поведінка й динамічна палітра в нас справді пітер-подібні — це
відкритий Material Design 3, а не чужа марка. Але логотип, напис, шрифт і
шпалери Google належать, і запозичувати їх не можна (деталі —
[docs/PIXEL-PARITY.md](../docs/PIXEL-PARITY.md)). Тому вигляд у системі свій, а
структура — спільна зі стандартом.

## Ліцензії

- Знак, lockup, фавіконка, VectorDrawable, шпалери — Apache-2.0, як і решта репо.
- `fonts/*.woff2` — SIL Open Font License 1.1; тексти ліцензій лежать поруч
  (`manrope-OFL.txt`, `unbounded-OFL.txt`). Шрифти не змінювалися: це
  офіційні підмножини Google Fonts, їхні контрольні суми — у `TYPE.md`.

Жодного пропрієтарного ресурсу в цій теці немає; воркфлоу `policy` перевіряє
репо загалом, а `check-brand.sh` — саме бренд (см. нижче).

## Перевірка

```bash
build/scripts/check-brand.sh
```

Він підтверджує, що контрольні суми шрифт і шпалер збігаються з записаними в
`TYPE.md`, що обидва OFL-файли на місці, і що знак у SVG і у VectorDrawable
має однакову геометрію (ті самі чотири контури).
