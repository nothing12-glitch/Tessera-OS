# Шрифти

## Вибір

| Роль | Сімейство | Ліцензія | Де |
|---|---|---|---|
| інтерфейс і текст | **Manrope** 400 / 600 / 700 | SIL OFL 1.1 | сайт, наші застосунки |
| дисплейний напис (логотип, великі заголовки) | **Unbounded** 400 / 600 | SIL OFL 1.1 | `logo/tessera-lockup.svg`, шапка сайту |

Чому саме вони:

- Обидва — відкриті й поширювані разом із продуктом, на відміну від Product
  Sans / Google Sans, які є маркою Google і не можуть бути частиною нічого
  нашого (докладно — [docs/PIXEL-PARITY.md](../docs/PIXEL-PARITY.md)).
- Обидва мають повне покриття кирилиці, включно з українськими літерами.
- Manrope — напівгеометричний гуманіст: та сама стриманість, що в системного
  шрифта Android, але власний малюк літер. Завужені `letter-spacing` у
  великих розмірах, як в Unbounded, дають «дисплейний» голос без запозичень.

## Покриття української

Офіційні підмножини Google Fonts, які ми поклали до репо, накрито такими
діапазонами (це буквально `unicode-range` з CSS, що його віддав Google):

```
cyrillic: U+0301, U+0400-045F, U+0490-0491, U+04B0-04B1, U+2116
latin:    U+0000-00FF, U+0131, U+0152-0153, U+02BB-02BC, U+02C6, U+02DA,
          U+02DC, U+0304, U+0308, U+0329, U+2000-206F, U+20AC, U+2122, …
```

Тобто в `cyrillic`-підмножині є весь блоковий діапазон `U+0400–045F`
(букви `є`, `і`, `ї`) плюс `U+0490-0491` (`Ґ ґ`). Це перевірено на самих
файлах: `build/scripts/check-brand.sh` відкриває woff2, дістає з них таблицю
`cmap` і вимагає, щоб у кириличній підмножині були коди `0404 0406 0407 0490
0491` — тобто `є і ї Ґ ґ`. Обіцянка «є кирилиця» тому не віра в опис шрифта,
а факт із файлів.

## Контрольні суми

Файли у репо — незмінені офіційні підмножини. Суми знову ж перевіряє скрипт,
щоб оновлення сімейства не сталася непомітною підміною.

```

a30ddcd349703aff7464c34bef3fffdff405ee50c113440d7c8693c02d210972  manrope-latin.woff2
e30bf6a6063b6a47232bbd657e24c7cf4fdaf76fc2c50d92d9ee63e2ad2087cf  unbounded-cyrillic.woff2
22f9b928aa3928a896340422b54d690fbb5875c30eae4c106f029c61f2289fd6  unbounded-latin.woff2
```

Джерело: `fonts.gstatic.com/s/manrope/v20/…`, `fonts.gstatic.com/s/unbounded/v12/…`
(версії вказані в URL; `v20` і `v12` — саме вони на момент додавання).
Тексти ліцензій — `manrope-OFL.txt`, `unbounded-OFL.txt` поруч.

TTF-варіанти тих самих сімейств (варіативні, з репозиторія `google/fonts`) у
git не лежать — їх кладає `build/scripts/fetch-brand-fonts.sh` і звіряє за
сумою:

```

323b511be380c8d474ef030686b71aedde501f8d9cd46da558b7c40454372c3f  Unbounded-var.ttf (760 КіБ)
```

## Як підключити

### На сайті

Шрифт самохостований, зовнішніх запитів немає — сторінка працює офлайн:

```css
@font-face {
  font-family: "Manrope";
  src: url("fonts/manrope-latin.woff2") format("woff2");
  font-weight: 200 800;                 /* варіативний файл */
  unicode-range: U+0000-00FF, U+0131, U+0152-0153, U+2000-206F, U+2122;
}
```

Повний блок із чотирма `@font-face` — у `site/index.html`.

### В Android

Тут важлива деталь, про яку легко спотикнутися: **Android не вміє вантажувати
woff2**. `Typeface` і `fonts.xml` працюють із TTF/OTF. Тому:

- у застосунку — TTF в `app/src/main/res/font/` (або `assets/fonts/`) і
  `FontFamily` у Compose; woff2 для цього не підходить;
- у всій системі — власний `fonts.xml` у `/system/etc/fonts.xml` разом із
  `PRODUCT_COPY_FILES`, або вибір користувачем через механізм кастомних
  шрифтів бази.

Обидва шляхи поки що **не перевірені на зібраному образі**: образу немає.
TTF-доставку робить скрипт `build/scripts/fetch-brand-fonts.sh`, щоб у git не
лізали зайві бінарники; він же й кладе контрольні суми.
